# Bezpieczni w sieci 🕵️

Zestaw materiałów na zajęcia edukacyjne o bezpieczeństwie w internecie dla dzieci **10–13 lat**. Czas zajęć: **45 minut**.

Wszystkie przykłady używają **marek fikcyjnych** i nie kopiują żadnej prawdziwej strony.

## Co jest w zestawie

| Plik | Co to | Jak użyć |
|------|-------|----------|
| `index.html` | Strona-hub z linkami do wszystkiego | Punkt startowy — otwórz w przeglądarce |
| `slajdy.html` | Prezentacja (10 slajdów) | Wyświetl na rzutniku. ← → lub spacja = następny, `F` = pełny ekran |
| `phishing/index.html` | Demo fałszywej strony phishingowej | Pokaż dzieciom, potem kliknij „Pokaż pułapki" |
| `karty-pracy.html` | 5 kart pracy do druku | Otwórz i kliknij „Drukuj / zapisz PDF" |
| `scenariusz.html` | Scenariusz lekcji dla prowadzącego | Przeczytaj przed zajęciami (można wydrukować) |

## Jak przeprowadzić zajęcia

Pełny plan krok po kroku jest w `scenariusz.html`. W skrócie:

1. Wprowadzenie i kontrakt (5 min)
2. Dane osobowe — co jest tajemnicą (7 min) → karta 1
3. Hasła (5 min) → karta 2
4. **Phishing — gra w detektywa (15 min)** → demo + karta 3
5. Nieznajomi, hejt, fałszywe informacje (8 min) → karta 4
6. Podsumowanie — zasada STOP (5 min) → karta 5 (dyplom)

## Jak wrzucić na GitHub Pages

1. Utwórz nowe repozytorium (np. `bezpieczny-internet`), ustaw „Public".
2. Wgraj całą zawartość tego folderu (zachowaj podfolder `phishing/`).
3. Settings → Pages → Source: `main` / `/root` → Save.
4. Po chwili materiały będą pod `https://twojanazwa.github.io/bezpieczny-internet/`.

Demo phishingu będzie wtedy pod `.../bezpieczny-internet/phishing/`.

## Klucz odpowiedzi (dla prowadzącego)

**Karta 1 — co jest tajemnicą:**
- ✅ Mogę podać: ulubiony kolor, nick w grze, ulubiony film, ulubione zwierzę, imię postaci z bajki.
- 🔒 Tajemnica: adres domowy, nazwa szkoły, numer telefonu, hasło do konta, zdjęcie legitymacji.

**Karta 2 — hasła:**
- Słabe: `123456`, `kot`, `imię + data urodzenia`.
- Mocne: `MójKotJe3Ryby!`, `Zielony$Smok77@Lesie`.

**Karta 3 — zaznacz pułapki:** wszystkie 7 punktów jest podejrzanych (to właśnie 7 sygnałów phishingu). Punkt o kłódce jest pułapką myślową — kłódka NIE gwarantuje bezpieczeństwa.

**Karta 4 — prawda/fałsz:**
1. Kłódka = 100% bezpieczeństwa — **F**
2. Bank prosi o hasło przez link w SMS — **F**
3. Osoba z gry zawsze mówi prawdę — **F**
4. Zdjęcia/filmy mogą być przerobione przez AI — **P**
5. Gdy coś niepokoi, powiedz dorosłemu — **P**
6. To samo hasło do wszystkiego to dobry pomysł — **F**
